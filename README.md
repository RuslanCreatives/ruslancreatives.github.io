# Портфолио Руслана в виде AI-чата

Портфолио продуктового дизайнера, оформленное как интерфейс чата с ИИ. Слева вкладки с разделами, по центру ответы, которые «печатаются» с блоком размышлений, кейсами, цифрами и интерактивными элементами.

## Как открыть

Весь сайт — один файл `index.html`. Его можно открыть двойным кликом или запустить локальный сервер:

```bash
python3 -m http.server 4173
```

После этого откройте http://localhost:4173. Нужен интернет: шрифты и картинки кейсов загружаются из сети.

## Что внутри

- **Разделы:** О себе (Кто я, Почему AI, Как я работаю), Работы (Ozon, Lamoda, Сбер, Simetra), Контакты (Почта, Telegram, LinkedIn), CV.
- **Режимы ответа:** «Подробно» и «Коротко» (TL;DR).
- **Команды:** клик по полю ввода или `/` открывает список команд (`/ozon`, `/cv`, `/theme`, `/mini`, `/clear` и другие).
- **Интерактив:** перегенерация ответа, календарь акций Lamoda (версия 1 / версия 2), панель с экранами кейса, черновик письма.
- **Настройки** в профиле внизу слева: светлая, тёмная или системная тема и скорость ответа.

## Где менять данные

Почта, Telegram, LinkedIn, ссылка на CV и фото задаются в объекте `CONFIG` в начале скрипта в `index.html`. Тексты ответов лежат в объекте `R` там же.
